# Project Learning Topics and Resources

## How To Use This Guide

For each project, start with the Learn First topics in order. The goal is to build enough depth to run a paid discovery and scoped pilot safely.

Format per project:

- Learn First: foundational topics before building
- Learn For What: why those topics matter in delivery
- Starter Resources: practical docs/courses/videos

## Practical Next Step

Pick one project aligned with your target buyer and complete these in 2 weeks:

1. 1-page discovery questionnaire
2. 1-page pilot scope with acceptance criteria
3. 1-page KPI baseline/target scorecard
4. 1 architecture diagram
5. 1 short case-style summary
