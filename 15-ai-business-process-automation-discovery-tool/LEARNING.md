# Learning Guide: AI Business Process Automation Discovery Tool

## What You Need to Learn

This project is your consulting methodology tool. The key skills are structured interview design, workflow mapping, ROI modeling, and report generation. Unlike other projects, this one teaches you how to think like a strategy consultant while using AI to accelerate the discovery process. It is foundational for running any consulting engagement.

---

## Phase 1: Business Process Analysis Fundamentals (Week 1-2)

### Core Concepts
- Business process mapping techniques: swim lanes, process flows, value stream maps
- Identifying waste in processes: manual steps, duplication, waiting, rework
- Value vs non-value-adding activity classification
- Automation feasibility criteria: structured input, rule-based decisions, high volume

### Resources
- **YouTube**: "Business Process Mapping Tutorial" by Lucidchart — https://www.youtube.com/watch?v=9pBJ8UoFkEM
- **YouTube**: "Value Stream Mapping Explained" by Lean Enterprise Institute — https://www.youtube.com/watch?v=UrfHdYl3wHs
- **Article**: "Automation Opportunity Identification" — https://www.mckinsey.com/capabilities/mckinsey-digital/our-insights/where-machines-could-replace-humans
- **Book**: *The Goal* by Eliyahu Goldratt — constraint-based process thinking (classic)

## Phase 2: Discovery Interview Design (Week 2)

### Core Concepts
- Designing structured interviews with open and closed questions
- BPMN (Business Process Model and Notation) basics
- Interview facilitation: how to draw out process details
- Documenting current-state vs desired-state workflows

### Resources
- **YouTube**: "BPMN Tutorial" by BPMInstitute — https://www.youtube.com/watch?v=BwkNceoybvA
- **Article**: "Process Discovery Interview Guide" — https://www.process.st/process-documentation/
- **Tool**: Miro for process mapping — https://miro.com/
- **Tool**: draw.io (free) for workflow diagrams — https://app.diagrams.net/

## Phase 3: LLM-Assisted Interview and Analysis (Week 3)

### Core Concepts
- Using LLMs to generate discovery questions based on domain/role
- Extracting process bottlenecks from interview transcripts
- Classifying automation potential from unstructured process descriptions
- Generating current-state summaries from interview notes

### Resources

## Phase 4: ROI Modeling (Week 3-4)

### Core Concepts
- Time-and-motion analysis: FTE hours × hourly rate = cost
- Error rate and rework cost modeling
- Implementation cost estimation: discovery, build, change management
- Payback period and 3-year NPV calculations
- Sensitivity analysis: best case / base case / conservative scenarios

### Resources
- **YouTube**: "ROI Calculation for Software Projects" — https://www.youtube.com/watch?v=aMBTRB3q9Z4
- **Article**: "Business Case Template" — https://www.projectmanager.com/blog/business-case-template-project
- **Book**: *Business Analysis and Valuation* by Palepu and Healy — financial modeling context
- **Tool**: Google Sheets ROI calculator templates

---

## Phase 5: Opportunity Scoring and Prioritization (Week 4-5)

### Core Concepts
- Multi-factor scoring: ROI potential, implementation effort, data availability, risk
- Weighted scoring matrix design
- MoSCoW prioritization
- Building a roadmap from scored opportunities

### Resources
- **Article**: "Prioritization Frameworks" — https://www.productplan.com/learn/prioritization-frameworks/
- **YouTube**: "Decision Matrix Tutorial" — https://www.youtube.com/watch?v=XLlk-Mu7ZZQ
- **Tool**: Notion or Airtable for opportunity tracking
