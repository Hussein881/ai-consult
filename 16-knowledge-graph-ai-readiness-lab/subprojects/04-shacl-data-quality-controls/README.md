# Subproject 04: SHACL Data Quality Controls

## Capability Goal

Implement SHACL-based validation and data quality controls for graph reliability.

## Learn First

- SHACL shapes and constraints
- data quality dimensions (accuracy, completeness, consistency)
- quality monitoring and threshold design

## Implement

1. Write SHACL shapes for critical entities.
2. Validate graph data against constraints.
3. Create quality scorecard and failure categorization.
4. Define remediation workflow for failed validations.

## Deliverables

- SHACL shapes library
- validation run output and error catalog
- data quality scorecard

## Exit Criteria

- critical entity classes are validated by automated rules
- failures are categorized and routed consistently
- quality scores are measurable over time

## Starter Resources

- W3C SHACL spec: https://www.w3.org/TR/shacl/
- pySHACL docs: https://github.com/RDFLib/pySHACL
- Great Expectations docs: https://docs.greatexpectations.io/
