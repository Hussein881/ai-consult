# Subproject 05: Entity Resolution and MDM

## Capability Goal

Drive entity resolution and master data management practices for trustworthy graph identities.

## Learn First

- duplicate detection patterns
- confidence scoring for record matching
- golden record and survivorship rules

## Implement

1. Define duplicate scenarios and match features.
2. Build low/medium/high confidence matching rules.
3. Implement human review path for uncertain matches.
4. Define golden-record survivorship logic.

## Deliverables

- entity resolution policy
- confidence rubric
- golden-record rules and stewardship workflow

## Exit Criteria

- duplicate reduction is measurable
- uncertain matches are reviewed safely
- downstream AI receives cleaner entity identity
