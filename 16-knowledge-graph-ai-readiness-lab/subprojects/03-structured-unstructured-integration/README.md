# Subproject 03: Structured and Unstructured Integration

## Capability Goal

Integrate structured and unstructured datasets into a coherent graph ingestion pipeline.

## Learn First

- ETL/ELT pipeline patterns
- document parsing and metadata extraction
- mapping source schemas to graph schema

## Implement

1. Ingest one structured source (CSV/JSON/database export).
2. Ingest one unstructured source (docs/tickets/notes).
3. Normalize fields and map to ontology classes.
4. Track source lineage for each graph record.

## Deliverables

- source inventory and mapping matrix
- ingestion pipeline scripts
- lineage and provenance report

## Exit Criteria

- both source types are integrated consistently
- mapping logic is repeatable and documented
- lineage is available for audit and debugging
