# Subproject 01: Enterprise Graph Foundation

## Capability Goal

Build and expand an enterprise knowledge graph foundation for a selected domain.

## Learn First

- graph data model basics (nodes, edges, properties)
- RDF/triples and graph semantics
- business domain scoping and boundary definition

## Implement

1. Choose one domain (support, compliance, engineering, ops).
2. Define 20-30 core entities.
3. Define 30-50 relationships.
4. Create initial graph schema and sample dataset.

## Deliverables

- domain scope brief
- baseline graph schema
- sample graph dataset and loading script

## Exit Criteria

- model covers core workflow objects and relations
- stakeholders can understand business meaning of entities
- graph can answer at least 10 business questions

- W3C RDF concepts: https://www.w3.org/TR/rdf11-concepts/
